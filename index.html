    This console shows only what VITALIS has actually received. Nothing here is pre-scripted — if no spans have been ingested, there is nothing to show. Send a real request through your instrumented stack, or post a span directly: 

    curl -X POST http://localhost:4318/v1/traces \
  -H "Content-Type: application/json" \
  -H "x-vitalis-api-key: $VITALIS_API_KEY" \
  -d '{"resourceSpans":[{"resource":{"attributes":[
        {"key":"service.name","value":{"stringValue":"Postgres"}}]},
      "scopeSpans":[{"spans":[{"traceId":"TX-DEMO-1","spanId":"s1",
        "name":"DB-Query","durationMs":3400,"attributes":[
          {"key":"db.lock_wait_ms","value":{"intValue":2900}},
          {"key":"db.holding_lock_pid","value":{"intValue":4242}}]}]}]}]}'

    Next evidence and diagnostic steps

    ⚠
    Nothing executes automatically. VITALIS is in observe-and-recommend mode. Automated remediation is deliberately the last thing built (Stage 4 of the roadmap), gated behind a real signed approval identity, RBAC scope, and a linked change ticket. This console never calls a control-plane API.
